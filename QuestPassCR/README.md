# QuestPassCR - Placa de Experiencias y Eventos

## Descripción del Proyecto
**QuestPassCR** es una plataforma web desarrollada como parte del avance de proyecto académico para la materia **SOFT-06 (Diseño y Programación Web)**. El sistema permite a los usuarios explorar, visualizar y solicitar reservas para diversas experiencias y eventos formativos en Costa Rica. Además, cuenta con un módulo administrativo para la gestión, edición y control de eventos y reservas solicitadas.

El proyecto está construido bajo los estándares web de **HTML5 Semántico** y **CSS3 nativo** (Modelo de caja, Flexbox y CSS Grid), garantizando accesibilidad, estados de foco visibles, contraste de color adecuado y adaptabilidad para dispositivos móviles y de escritorio.
